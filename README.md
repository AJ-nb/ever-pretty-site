# Ever-Pretty independent design study

Public website distribution. Independent and unofficial; no payments, real orders, passwords or email collection. Product facts and prices are archived snapshots. Original content belongs to its respective owners.

- Main site: https://ever-pretty-study.vercel.app/
- GitHub Pages: https://aj-nb.github.io/ever-pretty-site/

Only published website files are present here. The working source and research archive remain private. Media is delivered byte-for-byte from three companion GitHub Pages repositories. Some uncaptured source images still use the original store CDN. This is not a complete offline mirror.

GitHub Actions prefixes internal routes for the Pages subdirectory. Vercel serves the unchanged site directory at its root. No original-store checkout or tracking scripts are embedded. Availability depends on the visitor's network and hosting services; no all-region availability guarantee is made.
